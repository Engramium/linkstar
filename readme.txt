== Description ==

LinkStar adds a powerful and flexible link block to the WordPress block editor, making it easy to create visually engaging links, call-to-action buttons, and styled navigation elements.

Built for modern WordPress sites, LinkStar provides advanced styling controls, smooth hover effects, and essential link attributes—all without requiring custom CSS or code. It works seamlessly with Full Site Editing (FSE) themes and follows WordPress coding standards for performance and compatibility.

Whether you’re building landing pages, marketing sections, or custom layouts, LinkStar helps turn simple links into conversion-focused design elements.

**Key Features:**
* Advanced Styling Controls
* Customizable Hover Effects
* Icon Support
* SEO-Friendly Options (nofollow, new tab)
* Full Site Editing Compatible
* Lightweight & Optimized

**Ideal For:**
* Call-to-action buttons
* Styled navigation links
* Marketing and landing pages
* Header, footer, and template links in block themes

LinkStar is built natively for Gutenberg and designed to enhance both usability and design flexibility.

## Development & Source Code
LinkStar is open-source and developed publicly on GitHub.

GitHub repository: https://github.com/Engramium/linkstar

== Installation ==

1. Install through WordPress admin or upload to `/wp-content/plugins/linkstar`
2. Activate the plugin
3. Find "LinkStar" in the Widgets block category

== Frequently Asked Questions ==

= Is it compatible with my theme? =
Yes, LinkStar works with any properly coded WordPress theme.

= Does it work with Full Site Editing? =
Yes, fully compatible with FSE themes and modern WordPress features.
