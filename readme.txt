Create customizable link blocks with hover effects and advanced styling options.

== Description ==

Link Star adds a powerful link block to your WordPress editor with advanced styling options and hover effects. Perfect for creating call-to-action buttons and styled navigation elements.

**Features:**
* Advanced styling controls
* Customizable hover effects
* Icon support
* SEO-friendly options (nofollow, new tab)
* Full Site Editing compatible

== Installation ==

1. Install through WordPress admin or upload to `/wp-content/plugins/linkstar`
2. Activate the plugin
3. Find "Link Star" in the Widgets block category

== Frequently Asked Questions ==

= Is it compatible with my theme? =
Yes, Link Star works with any properly coded WordPress theme.

= Does it work with Full Site Editing? =
Yes, fully compatible with FSE themes and modern WordPress features.
